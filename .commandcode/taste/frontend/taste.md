# Frontend Taste

- Wants screens to fit the viewport with no unnecessary scrolling — explicitly asks for an "app like experience" without the unwanted scrollbar. Confidence: 0.7
- Treats vertical bloat ("taller than it needs to be") as a defect worth fixing, even when the page technically works. Confidence: 0.65
- Expects layout problems to be traced to real causes in the markup/stylesheet (e.g. unterminated CSS blocks that silently kill downstream rules) rather than patched with extra overrides. Confidence: 0.45
